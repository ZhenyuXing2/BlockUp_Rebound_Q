# BlockUp_Rebound_Q

BlockUp Rebound Q is a mini web-based canvas game designed from ideas by Grade 3 students.

Designed by Daniel, Lennox, Miles, Naomi, and Miles.

Files
index.html - the full game in one self-contained HTML file.
How To Play
Mobile or iPad: tap the screen to jump.
Tap shop boxes to buy weapons.
Tap the backpack icons to activate stored weapons.
Desktop:
Space jumps.
B buys a regular blaster.
C buys an ice blaster.
R activates a stored regular blaster.
I activates a stored ice blaster.
Enter pauses.
Why Host It
iPhone and iPad Safari may not open or run local .html files reliably from Files, AirDrop, email, or iCloud.
