# BlockUp_Rebound_Q

BlockUp Rebound Q is a mini web-based canvas game designed from ideas by Grade 3 students.

Designed by Daniel, Lennox, Miles, Naomi, and Miles.

Files
index.html - the full game in one self-contained HTML file.
How To Play
Mobile or iPad: tap the screen to jump.
Tap shop boxes to buy weapons.
Tap the backpack icons to activate stored weapons.
Desktop:
Space jumps.
B buys a regular blaster.
C buys an ice blaster.
R activates a stored regular blaster.
I activates a stored ice blaster.
Enter pauses.
Why Host It
iPhone and iPad Safari may not open or run local .html files reliably from Files, AirDrop, email, or iCloud. The game works best from a normal https:// website link.

Quick Deploy With Netlify Drop
Open Netlify Drop.
Drag the blockup-rebound-q-site folder or blockup-rebound-q-site.zip onto the page.
Netlify will create a public website link.
Open that link on iPhone or iPad.
Deploy With GitHub Pages
Create a new GitHub repository.
Upload index.html from this folder.
In the repository settings, enable GitHub Pages.
Set the source to the main branch root.
Open the generated GitHub Pages URL on iPhone or iPad.
Local Testing
Opening index.html directly works in many desktop browsers, but mobile Safari is stricter. For local network testing, serve the folder with a small web server and open the computer's local network URL from the iPhone or iPad.
